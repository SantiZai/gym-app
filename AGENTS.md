# Project Context: Gym App

A Next.js 15+ application using React 19, Supabase, and Tailwind CSS.

## Development
- **Dev Server:** `pnpm dev` (uses `--turbopack`)
- **Build:** `pnpm build` (uses `--turbopack`)
- **Linting:** `pnpm lint`

## Architecture
- **Framework:** Next.js (App Router)
- **Auth/DB:** Supabase
- **UI Components:** Built using Tailwind CSS, Radix UI primitives, Lucide icons, and Recharts/Chart.js for analytics.

## Conventions
- Follow Next.js App Router patterns in the `app/` directory.
- Use `pnpm` as the package manager.
